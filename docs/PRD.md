# PRD：世界杯胜率预测台 — 多页面重构

## 1. 项目信息

- **Language**: 中文
- **Programming Language**: 纯静态 HTML + CSS + JS（无构建工具）
- **Project Name**: `wc-predictor-multipage`
- **部署方式**: GitHub Pages（纯静态文件）
- **原始需求**: 将当前单页面应用拆分为多页面，每个板块一个独立 HTML 页面，增加页面间导航系统

## 2. 产品目标

| # | 目标 | 衡量标准 |
|---|------|----------|
| G1 | **信息架构清晰化** — 各功能板块独立成页，用户不再需要在一个长页面中滚动寻找内容 | 每个页面加载 ≤ 2 个核心数据源，首屏可见核心内容 |
| G2 | **移动端体验优化** — 页面间导航符合移动端操作习惯，微信内嵌浏览器兼容 | 底部 Tab 导航一键切换，无页面刷新闪白 |
| G3 | **功能模块解耦** — 各页面 JS/CSS 独立，降低单文件复杂度，便于后续独立迭代 | 单页面 JS ≤ 当前 app.js 的 50%，CSS 按页拆分 |

## 3. 页面规划

当前 `index.html` 包含 6 个板块，重构为 6 个独立页面：

| 页面 | 文件名 | 来源板块 | 核心功能 | 关键数据源 |
|------|--------|----------|----------|------------|
| **首页** | `index.html` | Hero 区域 + 预测器 | 赛事倒计时、Elo+泊松预测、预测卡片分享 | `teams.json`, `h2h.json` |
| **实时赛况** | `live.html` | `#live` 区域 | 实时比赛流、重点赛程、比分更新 | football-data.org API, `feed.json`, `fixtures.json` |
| **球队百科** | `teams.html` | `#teams` 区域 | 球队卡片列表、搜索筛选、点击选入预测 | `teams.json` |
| **夺冠热榜** | `ranking.html` | `#ranking` 区域 | Elo 评分排行、分档展示 | `teams.json` |
| **球迷社区** | `community.html` | `#community` 区域 | 帖子列表、发帖回帖、点赞、分类筛选 | Supabase `posts`/`replies` |
| **（预留）** | — | — | 帖子详情页可作为社区页内弹窗保留，或后续独立为 `post.html` | — |

### 3.1 各页面功能详述

#### 首页 (index.html)
- Hero 区域：赛事倒计时、开幕战信息、快捷入口按钮
- 预测器：选队 → 调参 → 查看胜率/比分/倾向 → 历史交锋 → 分享卡片
- 讨论入口：预测结果下方"前往社区讨论"按钮，跳转到社区页并带 `match_key` 参数
- 免责声明

#### 实时赛况 (live.html)
- 赛事实时流（API 数据 + 本地 feed.json 融合）
- 重点赛程列表
- 数据来源标注 + 最后更新时间
- 5 分钟轮询刷新（保留现有逻辑）

#### 球队百科 (teams.html)
- 搜索框 + 小组筛选 + 足联筛选
- 球队卡片网格（国旗、名称、评分、攻防值、风格标签）
- 点击球队卡片 → 跳转首页预测器并自动填入队伍（URL 参数 `?a=巴西&b=阿根廷`）

#### 夺冠热榜 (ranking.html)
- Elo 评分排序，分四档：冠军热门 / 强力竞争 / 中游力量 / 黑马潜力
- 球队行项点击 → 跳转球队百科或首页预测器

#### 球迷社区 (community.html)
- 分类筛选（全部 / 讨论 / 预测 / 资讯）
- 帖子列表（分页加载）
- 发帖弹窗（标题 + 正文 + 分类 + 关联比赛）
- 帖子详情弹窗（正文 + 回复列表 + 点赞 + 回复输入）
- URL 参数支持 `?match_key=巴西_vs_阿根廷`，从预测器跳转过来时自动筛选

## 4. 导航设计方案

### 方案：底部 Tab 栏（移动端优先） + 顶部导航栏（桌面端）

**移动端（≤ 768px）**：
- 固定底部 Tab 栏，5 个 Tab：
  - 🏠 首页 | ⚽ 赛况 | 🏟 社区 | 📊 热榜 | 📖 百科
- 当前页面 Tab 高亮（绿色）
- 顶部保留品牌名 + 登录按钮（精简）

**桌面端（> 768px）**：
- 顶部导航栏保留当前样式，链接改为页面跳转（`<a href="index.html">` 而非 `#anchor`）
- 底部 Tab 栏隐藏
- 汉堡菜单在移动端点击展开为垂直菜单

### 导航高亮规则
- 当前页面的导航项添加 `.active` 类，颜色为 `--green`
- 通过 JS 在每个页面 `DOMContentLoaded` 时比对 `window.location.pathname` 设置高亮

### 页面间跳转协议
| 跳转场景 | URL 格式 | 目标页面行为 |
|----------|----------|-------------|
| 球队百科 → 预测 | `index.html?a=巴西&b=阿根廷` | 首页自动填入两队并执行预测 |
| 预测器 → 社区讨论 | `community.html?match_key=巴西_vs_阿根廷` | 社区页按 match_key 筛选帖子 |
| 热榜 → 球队百科 | `teams.html?highlight=法国` | 百科页定位到该球队卡片 |
| 社区帖子分享 | `community.html?post=123` | 社区页直接打开帖子详情弹窗 |

## 5. 用户故事

### 首页
1. **As a** 球迷，**I want** 打开网站即看到赛事倒计时和预测器，**so that** 我能立刻开始预测比赛。
2. **As a** 球迷，**I want** 预测完后点击"前往社区讨论"直接跳到社区页，**so that** 我不用手动滚到页面底部。
3. **As a** 球迷，**I want** 把预测结果生成图片卡片分享，**so that** 朋友扫码就能来网站。

### 实时赛况
4. **As a** 球迷，**I want** 进入赛况页就看到最新比分和赛程，**so that** 我不用去其他 App 查。

### 球队百科
5. **As a** 球迷，**I want** 在百科页搜索和筛选球队，**so that** 我能快速找到关心的队伍。
6. **As a** 球迷，**I want** 点击球队卡片自动跳到预测器并填入队伍，**so that** 我能快速开始预测。

### 夺冠热榜
7. **As a** 球迷，**I want** 一眼看到各队 Elo 排名和分档，**so that** 我能了解哪些队是热门。

### 球迷社区
8. **As a** 球迷，**I want** 在社区页按分类浏览帖子，**so that** 我能找到感兴趣的话题。
9. **As a** 球迷，**I want** 从预测器直接跳到社区讨论某场比赛，**so that** 讨论有上下文。

### 导航
10. **As a** 移动端球迷，**I want** 底部 Tab 一键切换页面，**so that** 我不需要返回顶部找导航。

## 7. 技术约束

| 约束 | 当前方案 | 重构影响 |
|------|----------|----------|
| 无构建工具 | 纯 HTML/CSS/JS，CDN 引入 Supabase | JS 拆分为多个文件，通过 `<script>` 标签顺序加载 |
| GitHub Pages 部署 | 纯静态文件 | 多页面 = 多 HTML 文件，无需路由库 |
| 移动端优先 | 响应式 CSS | 底部 Tab 栏需 `position: fixed`，注意 iOS safe-area |
| 微信内嵌浏览器 | 无特殊处理 | 避免 `pushState`，用普通 `<a href>` 跳转 |
| 免费技术栈 | Supabase 免费版 + football-data.org 免费版 | 不变 |
| 预测算法 | 前端 Elo + 泊松计算 | 预测逻辑只在首页 JS 中，其他页面不加载 |
